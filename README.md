# 멜팅 대화 검수기

캐릭터와 시나리오를 입력하면 AI가 테스트 상대역으로 대화를 만들고, 맥락 이탈·설정 충돌·인물 간 기억 혼동 등을 검수합니다. 멜팅에서 실제로 나눈 대화를 붙여 넣어 분석할 수도 있습니다. 결과에는 오류 수정 방향, 재검수 질문, 구독자 취향에 맞춘 장면과 분위기 아이디어가 포함됩니다.

## 실행 방법 (Windows)

PowerShell에서 프로젝트 폴더로 이동한 뒤 다음 명령을 실행합니다. 가상환경 활성화 스크립트를 실행하지 않아도 됩니다.

```powershell
Set-Location -LiteralPath 'C:\Users\오구링\Desktop\멜팅검수기'
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

앱은 OpenAI와 Anthropic(Claude)에 각각 독립 검수를 요청하고, 결과를 나란히 보여 줍니다. 기본 모델은 OpenAI의 GPT-5.6 Sol과 Claude Fable 5.1이며, 왼쪽 메뉴에서 균형형·비용 절약형 모델로 바꿀 수 있습니다. 검수 전용 모델 선택은 생성된 테스트 대화에도 적용됩니다.

## API 키 설정

ChatGPT Plus/Pro와 Claude 유료 구독은 각 서비스 웹·앱 이용권입니다. 이 앱에서 자동으로 검수하려면 OpenAI API와 Anthropic API Console에 별도로 가입·결제하고 API 키를 준비해야 합니다. 검수 한 번에 양쪽 모델을 호출하므로 양쪽 API 사용료가 발생합니다.

로컬에서는 프로젝트 폴더의 `.streamlit/secrets.toml` 파일을 만들고 다음을 입력합니다. 파일은 저장소에 올리지 마세요.

```toml
OPENAI_API_KEY = "OpenAI API 키"
ANTHROPIC_API_KEY = "Anthropic API 키"
```

배포할 때는 호스팅 서비스의 서버 비밀 설정에 같은 두 값을 등록합니다. API 키는 사용자 화면에 표시되거나 브라우저로 전달되지 않습니다.

## 검수 순서

1. 캐릭터마다 이름·성격·말투·지식·관계를 구분해 입력합니다.
2. 현재 장면과 인물들이 알고 있는 사실을 시나리오에 적습니다.
3. 테스트 대화를 생성하거나 멜팅의 실제 대화를 붙여 넣어 분석합니다.
4. 오류 근거와 개선 문구를 확인하고, 추천 질문으로 다시 검수합니다.

인물이 많으면 한 장면에 모두 넣기보다 인물별 대화와 여러 인물의 장면을 나눠 반복 검수하세요. AI 테스트 결과는 실제 멜팅의 응답을 보장하지 않습니다. 실제 오류를 확인하려면 멜팅에서 나온 대화를 붙여 넣어 검수하는 것이 중요합니다.

## 데이터 안내

검수 요청에 입력한 캐릭터·시나리오·대화는 OpenAI와 Anthropic의 API로 각각 전송됩니다. API 키는 서버 비밀 설정에 보관하세요. 입력 자료를 전송하기 전에 두 서비스의 데이터 처리 정책을 확인하세요.
