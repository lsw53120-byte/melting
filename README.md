# 멜팅 대화 검수기

시나리오와 캐릭터 설정을 한 칸에 붙여 넣으면 ChatGPT에서 사용할 검수 프롬프트를 만듭니다. ChatGPT는 최소 5명의 서로 다른 가상 사용자 역할을 맡아 각각 대화를 시험하고, 문제의 원인·대화에 미친 결과·수정 위치·바로 적용할 수정 문구를 보고하도록 합니다. 멜팅 실제 대화도 넣으면 실제 관찰 오류와 가상 테스트 잠재 오류를 구분합니다.

## 실행 방법 (Windows)

PowerShell에서 아래 명령을 실행합니다.

```powershell
Set-Location -LiteralPath 'C:\Users\오구링\Desktop\멜팅검수기'
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 사용 순서

1. 캐릭터와 시나리오 원문을 한 칸에 붙여 넣습니다.
2. 가상 사용자 수를 최소 5명으로 설정하고, 사용자별 대화 왕복 횟수를 정한 뒤 `ChatGPT 검수 프롬프트 만들기`를 누릅니다.
3. ChatGPT에서 사용 가능한 성능 높은 모델을 선택하고 프롬프트를 붙여 넣습니다.
4. 결과를 앱에 붙여 넣고 저장하거나 Markdown 보고서로 내려받습니다.

API 키는 필요하지 않습니다. 앱은 ChatGPT를 직접 호출하지 않으므로, 생성한 프롬프트를 ChatGPT에 한 번 붙여 넣으면 ChatGPT가 여러 가상 사용자의 테스트 대화와 원인 분석을 한 번에 수행합니다. 결과 보고서를 앱에 붙여 넣어 저장하거나 Markdown 파일로 내려받습니다. 시나리오만 넣은 경우 발견 사항은 모의 테스트에서 예상한 잠재 오류입니다. 실제 멜팅 오류를 확인하려면 실제 대화를 같이 넣으세요.

## 보고서 구성

- 오류 유형·출처와 근거가 된 문장/대사
- 상대역의 말과 자연스러웠어야 할 반응
- 수정 위치, 현재 문구, 교체하거나 추가할 문구
- 수정으로 예방할 수 있는 오류와 재시험 질문
- 구독자 취향을 반영한 대화 소재와 분위기 아이디어

## 데이터 안내

앱 자체는 입력 원문을 외부 API로 보내지 않습니다. 사용자가 생성된 프롬프트를 ChatGPT에 붙여 넣으면 해당 내용은 ChatGPT 서비스로 전달됩니다. 민감한 설정을 입력하기 전에 ChatGPT의 데이터 정책을 확인하세요.
