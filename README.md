# 멜팅 대화 검수기

시나리오와 캐릭터 설정을 입력하면 OpenAI API를 통해 자동으로 가상 사용자 테스트를 진행하는 검수 앱입니다. AI는 최소 5명의 서로 다른 가상 사용자 역할을 맡고 캐릭터 답변까지 모의해, 대화에서 드러난 문제의 원인·영향·수정 위치·바로 적용할 수정 문구를 보고합니다. 멜팅 실제 대화 기록을 넣으면 모의 결과와 분리해 실제 관찰 오류를 분석합니다.

## 실행 방법 (Windows)

PowerShell에서 아래 명령을 실행합니다.

```powershell
Set-Location -LiteralPath 'C:\Users\오구링\Desktop\멜팅검수기'
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 사용 순서

1. 좌측 사이드바에 OpenAI API 키를 입력합니다. (서버/앱 설정에 이미 키가 등록돼 있으면 생략)
2. 캐릭터와 시나리오 원문을 한 칸에 붙여 넣습니다.
3. 분석 모델을 선택하고 가상 사용자 수와 사용자별 대화 왕복 횟수를 정한 뒤 `🤖 가상 검수 자동 실행`을 누릅니다.
4. AI가 자동으로 대화를 시뮬레이션하고 결과를 분석하여 화면에 보고서를 표시합니다.
5. 검수 보고서를 화면에서 직접 확인하거나 `.txt` 파일로 내려받습니다.

검수 전에도 화면의 `다운로드 기능 확인용 샘플 (.txt)` 버튼으로 브라우저 다운로드가 되는지 확인할 수 있습니다. 이 샘플은 테스트용 문구이며 실제 분석 결과가 아닙니다. 실제 보고서 다운로드 버튼은 API 검수가 성공한 뒤 표시됩니다.

> **API 키 관리 팁**: 관리자가 `.streamlit/secrets.toml` 파일 또는 환경 변수(`OPENAI_API_KEY`)에 API 키를 등록해두면 일반 사용자는 키를 입력하지 않아도 됩니다. 공개 앱에서 운영자 키를 설정하면 방문자가 운영자 계정에 API 비용을 발생시킬 수 있으므로, 접근 제한과 사용량 한도를 설정하세요. 개인 키를 웹 앱에 직접 입력할 때는 앱 운영자를 신뢰할 수 있는지 확인하세요.

## 모델과 비용

- 정확도 우선: GPT-5.5
- 균형형: GPT-5.4
- 비용 절약: GPT-5.4 mini

모델 가격은 토큰 사용량에 따라 달라집니다. 앱은 응답 사용량과 공식 단가를 바탕으로 회당 예상 비용을 표시합니다. OpenAI API 비용은 ChatGPT 구독료와 별도로 청구됩니다.

## 보고서 구성

- 오류 유형·출처와 근거가 된 문장/대사
- 상대역의 말과 자연스러웠어야 할 반응
- 수정 위치, 현재 문구, 교체하거나 추가할 문구
- 수정으로 예방할 수 있는 오류와 재시험 질문
- 구독자 취향을 반영한 대화 소재와 분위기 아이디어

## 데이터 안내

앱은 OpenAI API를 사용하여 데이터를 전송합니다. 민감한 설정을 입력하기 전에 OpenAI의 API 데이터 정책을 확인하세요.

## 다운로드 문제 해결

- `API 키가 없습니다` 메시지가 보이면 아직 보고서가 생성되지 않은 상태입니다. 사이드바에 API 키를 넣고 검수를 완료해야 실제 보고서 다운로드 버튼이 나타납니다.
- 샘플 TXT가 내려받아지면 브라우저의 다운로드 기능은 작동 중입니다. 실제 보고서가 나오지 않는 경우 API 키, 결제 설정 또는 모델 접근 권한을 확인하세요.
- 샘플도 내려받아지지 않으면 브라우저가 다운로드를 차단했는지 확인하고, 주소창 오른쪽의 다운로드 표시 또는 브라우저 다운로드 목록을 확인하세요.
