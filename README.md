# 멜팅 대화 검수기

캐릭터와 시나리오를 입력하면 ChatGPT와 Claude에서 실행할 검수 프롬프트를 만들어 줍니다. 두 서비스에서 받은 답을 붙여 넣어 나란히 비교하고, 맥락 이탈·설정 충돌·인물 간 기억 혼동 및 개선 제안을 확인하세요.

## 실행 방법 (Windows)

PowerShell에서 프로젝트 폴더로 이동한 뒤 다음 명령을 실행합니다. 가상환경 활성화 스크립트를 실행하지 않아도 됩니다.

```powershell
Set-Location -LiteralPath 'C:\Users\오구링\Desktop\멜팅검수기'
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

API 키 입력이나 별도 API 계정 설정 없이 사용할 수 있습니다. 검수 내용은 사용자가 직접 ChatGPT와 Claude에 붙여 넣습니다.

## 사용 순서

1. 캐릭터, 시나리오, 검수할 대화(있는 경우)를 입력하고 `검수 시작`을 누릅니다.
2. ChatGPT용 프롬프트를 복사해 ChatGPT에 붙여 넣고, 답변을 받습니다.
3. Claude용 프롬프트도 Claude에서 실행합니다.
4. 두 답변을 앱에 붙여 넣고 `두 결과 저장 및 비교`를 누릅니다.
5. 필요하면 비교 결과를 Markdown 파일로 내려받습니다.

테스트 대화를 고르면 두 서비스가 각자 가상 대화를 만든 뒤 검수합니다. 실제 멜팅 오류를 확인하려면 멜팅에서 나온 대화 내용을 입력하세요. 각 서비스의 모델 선택에서 사용할 수 있는 가장 성능 높은 모델을 고르면 됩니다.

인물이 많으면 한 장면에 모두 넣기보다 인물별 대화와 여러 인물의 장면을 나눠 반복 검수하세요. AI 테스트 결과는 실제 멜팅의 응답을 보장하지 않습니다. 실제 오류를 확인하려면 멜팅에서 나온 대화를 붙여 넣어 검수하는 것이 중요합니다.

## 데이터 안내

앱은 입력 내용을 자체 API로 보내지 않습니다. 사용자가 프롬프트를 복사해 ChatGPT와 Claude에 붙여 넣을 때 해당 서비스로 내용이 전달되므로, 민감한 설정을 공유하기 전에 각 서비스의 데이터 정책을 확인하세요.
